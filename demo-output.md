### Module: User Registration

**Ambiguities:**

> ⚠️ AMBIGUITY: "valid email format" — The spec does not define whether internationalized email addresses (IDN, Unicode local parts) are accepted or rejected. No maximum length for the email field is specified.

> ⚠️ AMBIGUITY: "special character" — The spec does not enumerate which special characters are accepted. It is unclear whether whitespace counts, or whether characters like `<`, `>`, and `"` that have HTML/SQL significance are permitted.

> ⚠️ AMBIGUITY: "Full Name: 2–100 characters" — It is unclear whether characters are counted in bytes or Unicode code points, and whether leading/trailing whitespace is stripped before validation.

**Edge Cases (not explicitly stated):**
1. Registration with an email that differs only in case from an existing account (e.g., `Test@Example.com` vs `test@example.com`) — uniqueness check may be case-sensitive.
2. Full Name consisting entirely of whitespace characters (e.g., two spaces) may pass the 2-character length check but should be rejected.
3. Submitting the registration form twice in rapid succession (double-click or network retry) may create duplicate accounts.
4. Phone number field submitted as `0000000000` — technically matches format rules but may be an invalid real number.

**Security Threats:**
- SQL Injection via email, full name, or phone fields.
- XSS via Full Name field stored in the database and rendered in UI.
- Account enumeration via registration error messages (e.g., "Email already exists" leaks valid emails).
- Email bombing: attacker registers many accounts with victim's email, flooding their inbox.

> ⚠️ AMBIGUITY: "reset link valid for 1 hour" — The spec does not state whether clicking the link and landing on the new-password form consumes the link, or whether the link remains valid until the form is submitted.

**Edge Cases (not explicitly stated):**

**Security Threats:**

> ⚠️ MISSING SECURITY REQ: Password Reset — No notification to user's registered email that a password reset was completed (audit trail alert).
